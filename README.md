# 📜 Announcement Board (Дошка оголошень)

Це повнофункціональний веб-застосунок для розміщення та перегляду оголошень. Проект був розроблений як практичне завдання для демонстрації навичок Full-Stack розробки (Node.js, Express, EJS, Prisma).

## 📋 Про проект

Дошка оголошень — це класичний веб-інструмент для публікації товарів, послуг або вакансій. Застосунок дозволяє користувачам керувати своїми оголошеннями через зручний інтерфейс з підтримкою фільтрації, сортування та пагінації.

### Реалізовані функціональні можливості:

1.  **Головна сторінка:** Список оголошень у вигляді карток.
    * **Пошук:** Динамічний пошук за назвою.
    * **Сортування:** Можливість вибору "Новіші спочатку" або "Старіші спочатку".
    * **Пагінація:** Посторінковий вивід (10 оголошень на сторінку) зі збереженням параметрів фільтрації.
2.  **Детальний перегляд:** Сторінка з повною інформацією про оголошення.
3.  **Керування оголошеннями:**
    * **Створення:** Форма з валідацією на стороні сервера та клієнта.
    * **Видалення:** Реалізоване через `fetch` API та HTTP метод `DELETE` з підтвердженням користувача.
4.  **Валідація та обробка помилок:**
    * Серверна валідація даних форми.
    * Обробка `404 Not Found` та `500 Server Error`.

## ⚙️ Інструкція зі встановлення

### 1. Попередні вимоги

Переконайтеся, що у вас встановлено:

- Node.js (версії 18+)
- npm або yarn

---

### 2. Встановлення залежностей
Клонуйте репозиторій та встановіть необхідні пакети:

```bash
git clone https://github.com/ErnestSosnovskyi/AnnouncementBoard.git
cd AnnouncementBoard
npm install
```

---

### 3. Налаштування бази даних
Проект використовує Prisma ORM. Для створення структури бази даних виконайте міграцію:

```bash
npx prisma migrate dev --name init
```

Це автоматично створить файл dev.db та таблицю Announcement згідно зі схемою.

---

### 4. Запуск проекту

Запустіть сервер:

```bash
node app.js
```

Після запуску відкрийте браузер і перейдіть за адресою: `http://localhost:3000`.

Для зручного перегляду даних у базі даних використовуйте Prisma Studio:

```bash
npx prisma studio
```

## 📝 Валідація даних

Серверна валідація гарантує коректність даних:
* Назва: 5–100 символів.
* Опис: мінімум 10 символів.
* Ціна: додатне число.
* Контакти: мінімум 5 символів.
* У разі помилок форма повертається користувачеві зі збереженням введених даних та повідомленнями про помилки.
